## ⚙️ Встановлення

1. Клонуй репозиторій:
   ```bash
   git clone https://github.com/your-username/valera-quiz.git
   cd valera-quiz
   ```

2. *(Необов'язково)* створи віртуальне середовище:
   ```bash
   python -m venv venv
   source venv/bin/activate      # Linux / macOS
   venv\Scripts\activate         # Windows
   ```

3. Встанови залежності:
   ```bash
   pip install PyQt5
   ```
   або з файлу:
   ```bash
   pip install -r requirements.txt
   ```

## 📝 Як додати своє запитання

Відкрий `questions.py` і додай новий елемент до списку:

```python
{
    "question": "Що найбільше любить Валера?",
    "answers": ["Мед", "Рибу", "Малину", "Усе одразу"],
    "correct": 3
}
```

> 💡 **Порада:** індекс `correct` починається з `0`.
